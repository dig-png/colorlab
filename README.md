# ColorLab — песочница цветов

Одностраничное веб-приложение для работы с цветом: конвертация HEX ↔ RGB ↔ HSL, генерация
гармоничных палитр, проверка контраста по WCAG 2.1, библиотека палитр и интерактивный справочник.
Бэкенда нет: все вычисления и хранение данных выполняются в браузере.

## Возможности

- **Конвертер** (`/converter`) — синхронный пересчёт HEX/RGB/HSL, color picker, копирование значений,
  шкалы tints/shades, валидация ввода, ссылка на цвет через `?hex=`.
- **Генератор** (`/palette`) — схемы комплементарная, аналоговая, триада, тетрада, монохромная и
  случайная; 3–6 цветов; блокировка цветов; перестановка drag-and-drop и кнопками; ручная правка;
  сохранение в библиотеку; экспорт CSS/JSON/HEX.
- **Контраст** (`/contrast`) — коэффициент 1:1…21:1, уровни AA/AAA для обычного и крупного текста,
  предпросмотр, инверсия пары, подбор ближайшего доступного оттенка.
- **Библиотека** (`/library`) — каталог предустановленных палитр, пользовательские палитры в
  `localStorage`, поиск и фильтр по тегам, редактирование, удаление с подтверждением, экспорт и
  импорт коллекции в JSON.
- **Справочник** (`/cheatsheet`) — цветовые модели, интерактивная демонстрация HSL, схемы гармонии,
  стандарты WCAG 2.1, поиск по материалам.
- Светлая и тёмная темы, адаптив от 360 px, клавиатурная доступность, Error Boundary, страница 404.

## Стек

React 19 + TypeScript (strict), Vite, React Router (history), Zustand, chroma-js, react-colorful,
dnd-kit, CSS-модули. Тесты — Vitest + React Testing Library, линтер — ESLint, форматирование —
Prettier.

## Установка и запуск

Требуется Node.js 20 LTS или новее.

```bash
npm ci          # установка зависимостей
npm run dev     # dev-сервер, http://localhost:5173
npm run build   # сборка в dist/
npm run preview # предпросмотр собранной версии
```

| Команда | Назначение |

## Архитектура

```
src/
├── components/      # Layout, Toast, ColorField, PickerPanel, CopyButton, ConfirmDialog, ErrorBoundary
├── data/            # предустановленный каталог палитр (статический JSON-совместимый модуль)
├── lib/             # чистая логика без React
│   ├── color.ts     # парсинг и конвертация HEX/RGB/HSL, шкалы, читаемость текста
│   ├── contrast.ts  # WCAG Contrast Ratio, уровни AA/AAA, подбор доступного оттенка
│   ├── harmonies.ts # алгоритмы цветовых гармоний
│   ├── exporters.ts # CSS/JSON/HEX-экспорт и импорт коллекции
│   ├── storage.ts   # безопасная работа с localStorage (версия схемы, восстановление)
│   ├── clipboard.ts # копирование и скачивание файлов
│   └── types.ts     # общие типы палитр
├── pages/           # пять разделов + 404
├── store/           # Zustand: цвет/тема, библиотека, тосты
├── styles/          # глобальные токены, темы, базовые элементы
└── test/            # настройка Vitest
```

### Состояние

- `useColorStore` — текущий цвет и тема; сохраняется в `localStorage` (`colorlab:settings`) и
  переиспользуется разделами «Конвертер» и «Контраст».
- `useLibraryStore` — пользовательские палитры (`colorlab:library`): добавление, правка, удаление,
  пакетный импорт.
- `useToastStore` — очередь всплывающих уведомлений.

Все записи в `localStorage` обёрнуты в конверт `{ "version": 1, "data": ... }`. Битые данные,
чужая версия схемы или недоступное хранилище приводят к старту с настройками по умолчанию — приложение
не блокируется.

### Маршруты

`/converter`, `/palette`, `/contrast`, `/library`, `/cheatsheet`, `*` → 404. History-роутинг; на
GitHub Pages используется SPA-фолбэк через `public/404.html`.

## Формат JSON

Экспорт одной палитры:

```json
{
  "name": "Закат в офисе",
  "colors": ["#f97316", "#fb7185", "#c026d3", "#7c3aed", "#1e1b4b"]
}
```

Экспорт коллекции (он же формат импорта):

```json
{
  "version": 1,
  "data": [
    {
      "id": "0f3c…",
      "name": "Закат в офисе",
      "tags": ["тёплая", "интерфейс"],
      "colors": ["#f97316", "#fb7185", "#c026d3", "#7c3aed", "#1e1b4b"],
      "createdAt": "2026-11-26T10:00:00.000Z"
    }
  ]
}
```

Импорт также принимает простой массив палитр и объект `{ "palettes": [...] }`. Цвета
нормализуются к `#rrggbb`, палитры с менее чем тремя валидными цветами пропускаются.

## Тестирование и качество

`npm test` прогоняет модульные тесты конвертации, контраста, гармоний, хранилища и экспорта.
`npm run coverage` контролирует покрытие `src/lib` на уровне не ниже 80 %. `npm run lint` и
`npm run build` (включая `tsc -b` со `strict: true`) должны проходить без замечаний.

## Деплой

Пуш в `main` запускает GitHub Actions: lint → tests → build → публикация на GitHub Pages
(`.github/workflows/deploy.yml`). Для project-сайта база сборки автоматически становится
`/colorlab/`.
